## 三、主力脚本 daily_scan_push.py 详解

### 8步流水线

```
Step 1: 持仓风控检查 → 逐只检查卖出条件(跌破黄线/峰值回撤/ATR止损/0AMV翻空/熔断)
Step 2: 执行卖出 → 触发条件自动清仓，记录交易到trade_history
Step 3: 扫描买入信号 → 四大共识硬过滤 + 冷却期过滤(5天内不再买入同一只)
Step 4: 执行买入 → 有空位自动建仓，MVO权重排序，计算佣金/滑点
Step 5: 保存持仓 → portfolio.json + trade_log.json
Step 6: LLM中长期分析 → DeepSeek V4 Pro分析持仓股+新买入股
Step 7: 计算组合概况 → 总资产/收益/现金/持仓市值/历史胜率
Step 8: 生成推送消息 → 6大板块Server酱推送
```

### ScanPortfolio 持仓管理类

与 `live_trader.py` 的 `LivePortfolio` 共享同一个 `portfolio.json`，数据结构完全兼容：

| 字段 | 说明 |
|------|------|
| `initial_cash` | 初始资金 |
| `cash` | 当前现金 |
| `positions` | 当前持仓 (ts_code → 详情) |
| `trade_history` | 历史交易记录 |
| `recent_sells` | 最近卖出记录 (用于冷却期) |
| `last_update` | 最后更新时间 |

### Server酱推送内容 (6大板块)

| 板块 | 内容 |
|------|------|
| 一、大势判断 | 0AMV日线/周线 + 熔断器 + 上证指数 |
| 二、组合概况 | 总资产、总收益、现金、持仓市值、持仓数、可用仓位、历史胜率 |
| 三、当前持仓 | 每只股票的买入价、现价、收益、回撤、持仓天数、状态、操作建议 |
| 四、今日卖出 | 卖出价、买入价、收益、持仓天数、卖出原因 |
| 五、今日买入 | 买入价、RADE概率、ATR、MVO权重、滑点 |
| 六、🤖 AI中长期分析 | DeepSeek V4 Pro对每只持仓股/新买入股的中长期分析 |

推送标题格式：`v9.0带盘 2026-05-27 持仓3仓 收益+0.1%`

## 四、四层递进风控体系

| 层级 | 模块 | 核心逻辑 | 拦截效果 |
|------|------|---------|---------|
| Layer 1 | oamv_filter | 0AMV迟滞：X≥4%翻多，X≤-2.3%翻空，周线EMA-5二次确认 | BEAR时空仓 |
| Layer 2 | panic_breaker | 85%个股跌破20日均线 或 单日跌停>150只 | 触发时强制清仓 |
| Layer 3 | 四大共识硬过滤 | J<13冰点否决、PWVC>0.8否决、白>黄强制、振幅不足否决 | 过滤虚假信号 |
| Layer 4 | 冲击成本过滤 | impact = 0.4×√(参与率) + 0.001，滑点>1%否决 | 过滤流动性不足 |

### 卖出条件（持仓风控）

| 条件 | 阈值 | 说明 |
|------|------|------|
| 熔断器触发 | 85%跌破MA20 / 跌停>150 | 立即清仓 |
| 0AMV日线BEAR | X < -2.3% | 清仓 |
| 跌破黄线 | 收盘 < 黄线 | 中线破位 |
| 峰值回撤 | ≥ 8% | 止盈 |
| ATR止损 | ≥ 1.5×ATR | 从峰值回撤 |
| 最小持仓 | 3天 | 防止频繁交易 |

## 五、特征工程管线

```
原始K线 → 无菌清洗 → 特征工程(31维) → 分歧特征 → SSA降噪 → 路径签名(12维) → 市场上下文
```

### 43个特征 = 31传统 + 12路径签名

**传统特征 (31维)**:
- 价格区间(price_zone)、J值区间(j_zone)、K线形态(k_pattern)
- TEMD、黄线斜率符号/归一化、量比(vol_ratio_20)
- 5日/20日量比、量变化、ATR比率
- 白线>黄线、白黄距离、MACD值、DIF值
- MACD>0、RSI值、J原始值、J 5日最小值
- J上升、距离百分比、1日/5日收益率
- 20日价格位置、低>黄线、指数黄线斜率
- 指数State2概率、行业超卖、PWVC
- 收盘位置20、PWVC分布、J_clean、累积分数

**路径签名 (12维)**:
- 3维路径(价格变化率/量比变化率/J值变化率)，窗口5天
- Level-1: 3维签名
- Level-2: 9维交叉签名

### 关键特征说明

- **PWVC**: 看最高价/开盘价位置而非收盘价，高位放量阴线3天否决窗口
- **累积分数(accumulation_score)**: 量能爆发+金叉+低位三重加权
- **J_clean**: SSA降噪后的J值，消除高频噪声

## 六、模型层

### CatBoost主模型
- 43个特征，4个类别特征(price_zone, j_zone, k_pattern, pwvc_distribution)
- 买入阈值: 0.65 (RADE概率≥65%)
- 正则化: l2_leaf_reg=8, max_depth=4, auto_class_weights=Balanced

### ChebyKAN辅助模型
- Chebyshev多项式KAN网络: hidden_dim=16, poly_degree=4
- 使用AMSE损失训练 (ω=10，方向判断错误10倍惩罚)

### RADE双模型集成
- 自适应权重: `w_cb = sigmoid(γ × AMV_bias × ATR_ratio × 100)`
- CatBoost权重范围[0.2, 0.9]，KAN权重=1-w_cb
- 市场活跃度高时更信任CatBoost，低活跃度时增加KAN权重

### HMM市场状态识别
- 3状态高斯HMM: State1=上升, State2=黄金回调, State3=破位下跌
- State2概率≥0.65时允许买入

### 三重边界标签
- 上界=+1.5×ATR，下界=-0.8×ATR，时间界=5天
- 先触碰上界=正样本(1)，先触碰下界=负样本(0)

## 七、组合优化

### CostAwarePortfolioOptimizer (主力)
- Block Bootstrap 500场景 (匹配0AMV状态)
- 凸优化: `max(μ'w - λ×w'Σw - γ×cost(w))`
- 成本项: 市场冲击 + 买卖价差
- 约束: 单资产≤25%，总权重≤75%

### AlphaGlass可解释组合 (辅助)
- PyTorch端到端: 可微排序+Top-K掩码
- 自动选出最重要的3只股票
- Sharpe比率损失

## 十二、v10.0升级教训 (已回退)

| 升级方案 | 问题 | 回测结果 |
|---------|------|---------|
| Lead-Lag路径签名 | d=6时42维签名，总特征74维，样本不足 | +66.23% vs v9.0 +143.92% |
| Isotonic概率校准 | 压缩高概率信号，错失大行情 | 过于保守 |
| 动态买卖价差 | 缩量时过度惩罚 | 错杀缩量反弹股 |
| 分数凯利公式 | shrinkage过激进 | 仓位压缩过度 |

**教训**: 特征维度爆炸是量化模型大敌；校准和shrinkage在A股T+1环境下适得其反。代码保留在 isotonic_calibrator.py / dynamic_spread.py / fractional_kelly.py 中备用。
